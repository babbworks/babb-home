§ 01What it coversfive survival domains
01

Offline operation.

Tools must function without network connectivity — not merely degrade gracefully. If the network is down, the tool still works. Full stop.

offline-first · not offline-tolerant
02

Constrained devices.

Tools must work on low-memory, low-power, small-screen hardware, including feature phones. The frontier does not run the latest MacBook.

low-memory · low-power · KaiOS
03

Mixed skill levels.

Tools must be operable by people who did not build them and may not read English. The operator learned the tool yesterday. It must still work.

non-technical · multilingual
04

Data durability.

Records must be exportable in open formats, never locked to a vendor. Your data outlives every product cycle, every funding round, every pivot.

open export · no vendor lock
05

Long lifecycles.

Tools must be designed to operate for decades, not just until the next funding round. Century-capable is the design target.

decades · not quarters
06

Evidence-backed assessment.

The BASICS CLI examines code, configuration, documentation, and test coverage. It does not guess — it checks specific files, specific patterns, specific behaviors, and reports what it finds.

CLI assessor · not a checklist
