babb. — site pages

Sixteen HTML files in the system. Five primary-nav pages (six counting Homepage), plus ten supporting templates: Article, Workpads, the five Place subpages (Angle, Video, Audio, B-Roll, Field Notes), Person Subject + Person Contributor, and the World Read·Watch·Listen index. All single-file, no build step, design system shared. Each file links to all the others; open any to start.

paper · #faf8f3 ink · #1a1a1a alt · #a14a00 live · #2f7a3a term-bg · #141312 type · monospace (ui-monospace stack)

When this ports to Jekyll (per note 05), the tokens become _sass/_tokens.scss; the sysbar / masthead / footer become _includes/; and each page becomes its _layouts/ file. The specimen content here matches the Jekyll data model (Worlds slate, BABB-PLACE schema, Hamilton mill standing story).
